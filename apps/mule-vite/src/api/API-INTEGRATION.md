# API Integration

## Overview
API integration layer connecting to Foundry and Flux APIs.

## Files
- `flux.api.ts` - Flux API service configuration
- `foundry.api.ts` - Foundry API service configuration
- `index.ts` - API exports

## Usage
```typescript
import { fluxServices } from 'src/api/flux.api';
import { foundryServices } from 'src/api/foundry.api';
```
