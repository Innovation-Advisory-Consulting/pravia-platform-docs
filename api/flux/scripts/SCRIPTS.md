# Flux Scripts

## Overview
Utility scripts for Flux API operations.

## Available Scripts
- `migrate.sh` - Database migration script
- `post-migration-processor.ts` - Post-migration processing
- `update-build-info.js` - Build information updater

## Usage
```bash
# Run migrations
./scripts/migrate.sh

# Update build info
node scripts/update-build-info.js
```

See parent: `api/flux/FLUX-API.md`
