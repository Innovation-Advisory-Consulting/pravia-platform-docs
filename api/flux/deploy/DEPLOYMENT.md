# Flux Deployment

## Overview
Deployment scripts and configuration for Azure Container Apps.

## Contents
- `config.json` - Deployment configuration
- `deploy-azure-dev.sh` - Deploy to development
- `deploy-azure-qa.sh` - Deploy to QA
- `deploy-azure-test.sh` - Deploy to test
- `deploy-azure-uat.sh` - Deploy to UAT
- `AZURE_DEPLOYMENT.md` - Deployment documentation

## Usage

```bash
./deploy-azure-dev.sh
```
