# Account management Module

## Overview
CRUD operations for business accounts.

## Structure
- `dto/` - Data transfer objects
- `entity/` - Database entities
- `mappers/` - Data transformation
- `repository/` - Data access layer
- `accounts.controller.ts` - HTTP endpoints
- `accounts.service.ts` - Business logic
- `accounts.module.ts` - Module definition

## Purpose
Provides crud operations for business accounts functionality for Flux API.

See parent: `api/flux/FLUX-API.md`
