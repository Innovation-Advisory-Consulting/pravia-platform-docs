# Form submissions Module

## Overview
Form submission processing and management.

## Structure

- `entity/` - Database entities
- `mappers/` - Data transformation
- `repository/` - Data access layer

- `submissions.service.ts` - Business logic

Provides form submission processing and management functionality for Flux API.
