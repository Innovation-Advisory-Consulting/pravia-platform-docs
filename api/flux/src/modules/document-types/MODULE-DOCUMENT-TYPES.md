# Document types Module

## Overview
Define and manage document classifications.

## Structure
- `dto/` - Data transfer objects
- `entity/` - Database entities
- `mappers/` - Data transformation
- `repository/` - Data access layer
- `document-types.controller.ts` - HTTP endpoints
- `document-types.service.ts` - Business logic
- `document-types.module.ts` - Module definition

## Purpose
Provides define and manage document classifications functionality for Flux API.

See parent: `api/flux/FLUX-API.md`
