# Custom validators Module

## Overview
Custom validation decorators.

## Structure
- `dto/` - Data transfer objects
- `entity/` - Database entities
- `mappers/` - Data transformation
- `repository/` - Data access layer
- `validators.controller.ts` - HTTP endpoints
- `validators.service.ts` - Business logic
- `validators.module.ts` - Module definition

## Purpose
Provides custom validation decorators functionality for Flux API.
