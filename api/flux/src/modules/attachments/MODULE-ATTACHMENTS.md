# File attachments Module

## Overview
Upload, download, and manage file attachments.

## Structure
- `dto/` - Data transfer objects
- `entity/` - Database entities
- `mappers/` - Data transformation
- `repository/` - Data access layer
- `attachments.controller.ts` - HTTP endpoints
- `attachments.service.ts` - Business logic
- `attachments.module.ts` - Module definition

## Purpose
Provides upload, download, and manage file attachments functionality for Flux API.

See parent: `api/flux/FLUX-API.md`
