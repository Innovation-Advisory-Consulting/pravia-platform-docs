# Foundry Scripts

## Overview
Utility scripts for Foundry API operations.

## Available Scripts
- `migrate.sh` - Database migration script
- `post-migration-processor.ts` - Post-migration processing
- `query-contacts.mjs` - Contact query utility
- `update-build-info.js` - Build info updater
- `_archive/` - Archived scripts

## Usage
```bash
./scripts/migrate.sh
node scripts/query-contacts.mjs
```

See parent: `api/foundry/FOUNDRY-API.md`
