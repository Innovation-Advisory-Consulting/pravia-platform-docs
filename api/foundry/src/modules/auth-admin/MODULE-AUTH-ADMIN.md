# Auth Admin Module

## Overview
Authentication and Supabase integration.

- `entity/` - Database entities
- `mappers/` - Data transformation

- `auth-admin.service.ts` - Business logic
- `auth-admin.module.ts` - Module definition

Provides authentication and supabase integration functionality for Foundry API.
